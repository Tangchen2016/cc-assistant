# 按账号的浏览器环境

Mac 的「独立浏览器」页可选择默认配置或某个账号。号池行操作的「浏览器环境」可直达对应配置。

- 默认配置沿用现有浏览器设置。
- 账号的代理与时区逐项覆盖，未覆盖的项在下次使用时重新读取默认配置。
- 时区可继承默认、明确跟随系统、或指定 IANA 时区。
- 新账号有独立浏览器资料目录，继承网络设置不会共享 Cookie。
- 旧版关联默认浏览器的账号刷新仍可使用原关联；显式重新接入时切到对应账号环境。不会删除旧浏览器资料。
- 设置改变后不会强制关闭浏览器；运行状态提示需重新启动。由用户保存页面后关闭重开。
- 新注册账号在填写邮箱并打开官网时建立环境；同一邮箱重复使用同一资料目录。
- 环境配置单独保存在本机 registration/account-environments/environments.json，不随号池 JSON 跨设备导入。当前不修改 iOS Safari 或系统时区。

验收：继承、逐项覆盖、明确系统时区、默认变更、两账号目录隔离、重启持久化、旧关联、损坏文件拒绝写入。实号注册闭环尚待完成；本次不发布正式更新。
