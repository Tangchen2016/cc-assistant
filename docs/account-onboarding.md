# 账号接入

号池的“新增账号”提供三个入口：注册新账号并入库、接入已有账号、手动记录账号。账号指南的注册入口使用同一个接入流程。

## 注册新账号

1. 填写准备注册的邮箱。
2. 打开 Claude 官网，由本人完成注册、验证码和条款确认。
3. 返回 cc助手读取账号。识别邮箱必须与目标邮箱一致。
4. 核对身份后确认入库。同邮箱会更新已有记录；回收站中的邮箱需要先还原。

不向官网提交注册表单、验证码、付款或账号删除请求。

## 接入已有账号

Mac 可读取当前独立 Chrome 的登录身份，也可粘贴自己的 sessionKey。iPhone 原生版提供官网入口与 Session 接入，不能跨 App 读取 Safari 会话。

浏览器读取需要从接入流程打开独立 Chrome。若该浏览器已在运行且没有连接能力，先由用户关闭再重新打开；沿用原资料目录。只在用户选择该入口时启用绑定到 127.0.0.1 的随机调试端口。读取限定此 App 所属资料目录、所属进程和 claude.ai 页面，仅 GET `/api/account`。不读取、导出浏览器 Cookie；退出这个浏览器进程会关闭连接能力。

Session 只发往 `https://claude.ai/api/account`，禁止跳转，不写日志。Mac 使用浏览器菜单配置的 HTTP / SOCKS5 代理；不支持的代理类型会报错，不自动直连。iPhone 使用其当前网络环境。

## 本机保存

- 台账仍为 Application Support 下的 `Subscription Studio/accounts.json`，识别快照作为可选字段保存，旧记录兼容。
- 独立关联文件位于同目录 `private-sessions/<账号 UUID>.json`。Session 模式保存用户提供的凭据；浏览器模式只保存邮箱与环境 ID，不保存 Cookie。
- 目录权限 0700，文件权限 0600，并设置排除系统备份属性；不使用系统钥匙串。文件权限不是内容加密。
- 普通号池导入导出不包含关联文件。取消保留 Session 时仅保存本次身份资料；解除关联保留台账。
- 读取失败不覆盖已有资料。401 表示会话不可用，403 表示读取受限，不自动把账号标成停用。
- 套餐仅使用明确字段或单一组织的可识别档位；档位识别会标注来源。无结果时保留手工内容，不推算套餐到期日，也不把 Session 有效期当成订阅到期日。

## 验证边界

解析、HTTP 错误、跳转拦截、代理走向、凭据文件保护、同邮箱入库和解除关联竞态使用隔离测试。浏览器连接用无登录态临时 Chrome 验证；不读取用户其他浏览器资料。

真实官网登录后的字段和可访问性仍需用户在 App 内完成一次接入验证。网页内部接口可能变化；该功能不是官方 OAuth 客户端授权集成。

账号接口字段参考：[CodexBar 的 Claude Web API 实现](https://github.com/steipete/CodexBar/blob/main/Sources/CodexBarCore/Providers/Claude/ClaudeWeb/ClaudeWebAPIFetcher.swift)。
